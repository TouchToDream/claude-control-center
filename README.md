# Центр керування Claude Code

Локальна вебпанель для всіх сесій Claude Code на твоєму Mac. Сесії лишаються у звичних терміналах IDE, а панель показує їх в одному місці й дає відповідати з браузера або з маленької програми для Mac, яка відкривається гарячою клавішею поверх будь-якого вікна.

Це неофіційний інструмент, він не пов’язаний з Anthropic.

```text
Термінал IDE: проєкт А   ┐
Термінал IDE: проєкт Б   ├─ мод ⇄ локальний сервіс ⇄ сторінка панелі
Термінал IDE: проєкт В   ┘
```

## Що вміє

- Показує всі сесії за репозиторіями: хто працює, хто чекає на тебе, хто простоює.
- Показує переписку, виклики інструментів, контекст, ліміти, субагентів, змінені файли.
- Дає написати в сесію з браузера. Текст із `/` запускає команди й скіли, є підказки.
- Приймає скріншоти й файли: вставка з буфера, перетягування або скріпка.
- Керує чергою: повідомлення можна скасувати, відредагувати, вставити в поточний хід або зупинити хід і надіслати одразу.
- Дублює запити дозволу й питання Claude: відповісти можна і в терміналі, і в панелі, перша відповідь закриває запит.
- Показує прогрес тестів наживо, таймлайн за годину, етап поточного завдання.
- Показує diff змінених файлів і відкриває файл в IDE.
- Міняє модель і effort для окремої сесії, не чіпаючи глобальних налаштувань.
- Перейменовує, закриває й продовжує сесії.
- Відкривається гарячою клавішею поверх усіх вікон, на будь-якому екрані, і ховається тією самою клавішею.
- Надсилає сповіщення macOS про питання, запити дозволу, завершене завдання, помилки й упалі тести; на значку в меню видно, скільки непрочитаних.
- Надсилає сповіщення в Telegram, якщо ти це ввімкнеш.

Інтерфейс український.

## Вимоги

| Що | Версія |
|---|---|
| macOS | використовуються launchd, Keychain і команда `open`; Linux і Windows не підтримуються |
| Node.js | 26 або новіший |
| Claude Code | 2.1.304 або новіший; перевірено на 2.1.316 |
| Git | будь-яка сучасна версія |
| Xcode Command Line Tools | зі Swift 6 (Xcode 16 або новіші), лише для програми для Mac: `xcode-select --install`. Без них панель працює в браузері |
| macOS | 14 або новіша для програми для Mac |

Перевірено на підписці Max. На планах Team і Enterprise організація може обмежувати моди, а панель може не мати змоги схвалювати частину запитів дозволу.

## Встановлення

```sh
git clone https://github.com/TouchToDream/claude-control-center.git ~/claude-control-center
cd ~/claude-control-center
npm install
npm run setup
```

Команда `npm run setup`:

1. перевіряє Node і Claude Code;
2. збирає панель;
3. встановлює мод `control-center` у Claude Code на рівні користувача;
4. запускає локальний сервіс і вмикає його автозапуск через launchd;
5. збирає програму для Mac, кладе `Claude Control Center.app` у `~/Applications` і запускає її.

Без автозапуску сервісу: `npm run setup -- --no-autostart`. Без програми для Mac: `npm run setup -- --no-app`.

Відкрити панель:

```sh
npm run ccc -- open
```

Далі можна зробити закладку на `http://127.0.0.1:47821` або ввести в будь-якій сесії Claude Code команду `/control-center`, і панель відкриється на цій сесії: у програмі, якщо вона встановлена, інакше в браузері.

Сесія, яка не з’явилася в панелі, показується в списку «Без мосту». Виконай у ній `/reload-plugins`.

## Вкладення

У поле вводу можна вставити скріншот (⌘V), перетягнути файл або вибрати його скріпкою, до 20 МБ на файл. Сервіс кладе файл у `~/.claude-control-center/uploads/<сесія>/`, а до повідомлення додає рядок `[Вкладення: <шлях>]`, і Claude відкриває файл інструментом Read: картинки бачить, PDF і текст читає.

Справжнім вкладенням, як вставка в терміналі, це бути не може: Claude Code не розгортає вкладення в повідомленнях від мода. У режимі дозволів `auto` Claude читає файл без запиту, у звичайному попросить дозвіл, і його можна дати в панелі. Файли стираються через 14 днів.

## Програма для Mac

Під час першого запуску програма відкриє налаштування й попросить:

1. **Задати гарячу клавішу.** Натисни «Змінити» й потрібне поєднання. Без ⌘, ⌃ або ⌥ можна задати лише `` ` ``, `§` або F1–F20; символ такої клавіші перестане друкуватися в інших програмах.
2. **Дозволити сповіщення.** Якщо запит пропущено, у меню значка буде «Увімкнути сповіщення…», він відкриє потрібний розділ Системних параметрів.

Як це працює:

- Клавіша показує панель на екрані, де зараз курсор, поверх усіх вікон і повноекранних програм. Друге натискання ховає її, і фокус повертається туди, де ти був. Недописаний текст лишається на місці.
- Розмір і місце вікна програма запам'ятовує як частку екрана: розтягнув на пів екрана — і далі вона з'являється на пів екрана будь-якого монітора.
- Значок у верхньому меню показує кількість непрочитаних сповіщень і список останніх. Клік по сповіщенню відкриває його сесію.
- Про що сповіщати, вирішують перемикачі в панелі: кнопка з повзунками в шапці → «Сповіщення Mac». Про сесію, яку ти зараз бачиш у панелі, сповіщення не приходить.
- Сповіщення стає прочитаним, коли ти відкрив його сесію, клікнув по ньому, запит закрили будь-де (наприклад, у терміналі) або сесія почала новий хід.

Програма збирається з коду на твоєму Mac і підписується локально, тому macOS запускає її без попереджень. Готового `.dmg` немає.

## Перед встановленням: що це змінює

Мод завантажується в **кожну** сесію Claude Code на цій машині, у всіх репозиторіях, зокрема в уже відкриті.

Що робить мод:

- надсилає події сесії в локальний сервіс: повідомлення, виклики інструментів, стан ходу;
- опитує сервіс раз на 1,5 секунди;
- дублює запити дозволу й питання в панель;
- час від часу виконує `git rev-parse`, `git diff --numstat` і `git ls-files --others`.

Чого мод не робить: не викликає модель, не додає тексту в контекст Claude і не обходить правила дозволів. Якщо сервіс вимкнено, сесія працює як звичайно. Токени витрачаються лише на повідомлення, які ти сам надсилаєш із панелі.

Переписка зберігається локально в `~/.claude-control-center` на 14 днів.

Програма для Mac додає себе до об'єктів входу (вимикається в її меню), реєструє адреси `ccc://` і просить дозвіл на сповіщення. Інших дозволів (Accessibility, запис екрана) вона не просить.

## Команди

| Команда | Що робить |
|---|---|
| `npm run ccc -- open` | відкрити панель у програмі або браузері |
| `npm run ccc -- app` | зібрати й перевстановити програму для Mac |
| `npm run ccc -- status` | стан сервісу й автозапуску |
| `npm run ccc -- start` / `stop` | запустити або зупинити сервіс |
| `npm run ccc -- logs` | останні рядки логу |
| `npm run ccc -- autostart-on` / `autostart-off` | увімкнути або вимкнути автозапуск |

Якщо панель показує «Потрібен ключ доступу», відкрий її командою `npm run ccc -- open`: вона передасть ключ сама.

## Сповіщення в Telegram

Вони вимкнені, поки ти не налаштуєш бота, не ввімкнеш перемикач у шапці панелі й дзвіночок біля потрібного проєкту. Telegram працює незалежно від сповіщень Mac і, якщо ввімкнений, дублює їх за своїми правилами.

1. У Telegram відкрий @BotFather, надішли `/newbot`, скопіюй токен.
2. У панелі натисни кнопку з повзунками поруч із Telegram і встав токен. Він зберігається в Keychain.
3. Напиши боту будь-що або додай його в групу, натисни «Знайти чат» і вибери чат.
4. Натисни «Надіслати тестове», потім увімкни перемикач і дзвіночки.

Повідомлення йдуть через сервери Telegram. Надсилаються лише назва проєкту, сесії, гілка, статус і лічильники, без команд і тексту переписки. Назвою сесії може бути твоє перше повідомлення, якщо ти її не перейменував.

## Оновлення

```sh
cd ~/claude-control-center
git pull
npm install
npm run build
npm run ccc -- stop
npm run ccc -- start
npm run ccc -- app
```

Потім виконай `/reload-plugins` у відкритих сесіях.

## Вимкнення й видалення

Тимчасово вимкнути мод:

```sh
claude plugin disable control-center@claude-control-center
```

Видалити все (спершу вийди з програми через меню її значка):

```sh
cd ~/claude-control-center
rm -rf ~/Applications/"Claude Control Center.app"
npm run ccc -- autostart-off
npm run ccc -- stop
claude plugin uninstall control-center@claude-control-center
claude plugin marketplace remove claude-control-center
rm -rf ~/.claude-control-center
```

Остання команда видаляє ключ і історію панелі. Переписка в самому Claude Code лишається. Токен бота, якщо він був, спершу прибери кнопкою «Від’єднати» в налаштуваннях Telegram.

## Прогрес тестів

Сервіс читає вивід команди, тому в репозиторіях нічого налаштовувати не треба.

| Раннер | Що видно наживо |
|---|---|
| PHPUnit, ParaTest | точні лічильники `N / M` |
| `php artisan test` | виконано й упало; загальна кількість лише наприкінці |
| Jest | виконані й упалі файли; підсумок наприкінці |
| проєкти з `laravel/pao` | під агентом вивід один наприкінці, тому час оцінюється за попереднім запуском |

## Обмеження

- API модів Claude Code ще в ранньому доступі й може змінитися з оновленням.
- Панель читає недокументовані файли Claude Code: реєстр сесій і вивід команд. Без них вона працює, але бідніше.
- Закриті сесії панель відновлює через `claude --resume`, відкрити термінал IDE сама вона не може.

## Безпека

Сервіс слухає лише `127.0.0.1`. Мод ходить із ключем із `~/.claude-control-center/config.json` (права `600`), сторінка з cookie `HttpOnly`. Запити з чужим `Host` чи `Origin` відхиляються. Токени й ключі маскуються в моді ще до відправлення в сервіс.

## Стек

Мод на TypeScript, сервіс на Node.js без збірки (`node:http`, `node:sqlite`, `ws`), панель на React і Vite, програма для Mac на Swift (AppKit, WebKit). Як це влаштовано: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
